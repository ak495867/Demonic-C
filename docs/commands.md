# Commands

`dmc test` collects `#[test]` and `#[bench]` declarations. `dmc test --coverage` reports collection status. `dmc test --bench` reports benchmarks. `dmc doc` generates HTML documentation. `dmc build --release` emits an optimized executable. `dmc build --static` requests static linking. `dmc bundle` writes a distributable manifest. `dmc login`, `dmc publish`, and `dmc deprecate` manage local registry metadata.
